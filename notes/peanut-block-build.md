# Build and Deploy Peanut Block

1. Update source files as needed in: (project directory)\wp-block\peanut-block\src
2. Open terminal in: (project directory)\wp-block\peanut-block
3. Run `npm run build`.  To generate the production-ready files for the Peanut block in  (project directory)\wp-block\peanut-block\build
4. Run '.\peanut-block-deploy.ps1' to deploy the Peanut block to the the document root: (project directory)/web.root/wp-content/plugins/peanut/blocks/peanut-block
